# Exemplo Rápido: Laya + Pi Agent

1. Preencha o arquivo `.env.docker` com sua `DEEPSEEK_API_KEY`.
2. Abra esta pasta no VS Code e clique em **Dev Containers: Reopen in Container**.
3. O build instalará o **Pi**, todas as **skills** e baixará o **Laya**.
4. No terminal integrado rode `python teste_laya.py` para ver o Laya roteando um ticket.
5. Digite `pi` no terminal para começar a codar com a DeepSeek!
